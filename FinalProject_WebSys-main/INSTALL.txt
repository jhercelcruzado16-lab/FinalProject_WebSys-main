ReSource: TIP Student Marketplace
COMPLETE XAMPP INSTALLATION

1. Copy the entire ReSource_Final folder to:
   C:\xampp\htdocs\ReSource_Final

2. Start Apache and MySQL in XAMPP.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin/

4. Import:
   backend/database/resource_marketplace.sql

5. Open the website:
   http://localhost/ReSource_Final/

6. Database settings are in:
   backend/php/config/database.php

   Default XAMPP:
   host = localhost
   database = resource_marketplace
   user = root
   password = empty

7. Admin:
   The imported SQL creates this local development account:
   email: admin@tip.edu.ph
   password: admin123

   For a different admin, register an account using the website.
   Then, in phpMyAdmin, run:
   UPDATE users SET role='admin'
   WHERE email='YOUR_TIP_EMAIL@tip.edu.ph';

8. Listing images are physically stored in:
   backend/uploads/listings/

   The database stores their relative paths in listing_images.

9. Profile photos are stored in:
   backend/uploads/profiles/

10. Do NOT open PHP pages using file://.
    Use Apache through:
    http://localhost/ReSource_Final/

11. Configure email delivery before testing student login, registration, or
   forgot-password recovery.
   In C:\xampp\apache\conf\extra\httpd-xampp.conf, add these directives
   inside the existing <IfModule env_module> block near its other SetEnv
   lines, then restart Apache:

      SetEnv MAIL_HOST smtp.gmail.com
      SetEnv MAIL_PORT 587
      SetEnv MAIL_ENCRYPTION tls
      SetEnv MAIL_USERNAME your-sending-account@gmail.com
      SetEnv MAIL_PASSWORD your-new-google-app-password
      SetEnv MAIL_FROM_ADDRESS your-sending-account@gmail.com
      SetEnv MAIL_FROM_NAME ReSource

   Use a Gmail App Password (not the normal Google account password); the
   sending account must have 2-Step Verification enabled. MAIL_FROM_ADDRESS
   should match the authenticated account. Check the PHP/Apache error log if
   SMTP fails.

   IMPORTANT: The previous SMTP app password was embedded in project files
   and should be revoked in Google immediately. Generate a new App Password
   and configure only the new value in Apache as shown above.

The project separates browser-facing files in frontend/ from server-side files
in backend/. The root index.php forwards to frontend/index.php. The PHP API is
the persistent data layer for users, listings, images, favorites, cart,
purchases, messages, reports, and admin functions.

IMPORTANT:
Some UI state remains in localStorage; account and administrative actions use
the PHP/MySQL backend.
